1 PREDICT THE OUTPUT

Code
console.log("A");
setTimeout(() => console.log("B"), 0);
console.log("C");

Output
A
C
B

Explanation
A prints first then C prints right after because normal synchronous lines run right away on the call stack
setTimeout is async so its callback gets pushed to the task queue
even with 0ms delay the event loop waits until the main stack is totally clear before running B

3 PREDICT THE OUTPUT

Code
const orderPromise = new Promise((resolve, reject) => {
  reject(new Error("out of stock"));
});

orderPromise
  .then(result => console.log("Got:", result))
  .catch(err => console.log("Error:", err.message));

Output
Error: out of stock

Explanation
The promise fails right away with an error out of stock
then only runs when a promise resolves successfully
since it rejected javascript skips then completely and jumps straight to catch

7 PREDICT THE OUTPUT

Code
async function run() {
  console.log("1");
  await new Promise(resolve => setTimeout(resolve, 1000));
  console.log("2");
}

console.log("start");
run();
console.log("end");

Output
start
1
end
(1 second delay)
2

Explanation
await only pauses execution inside the run function
it does not block the main script outside
so start prints first then run starts and prints 1
when run hits await it pauses inside while the main thread keeps moving and prints end
after 1 second the promise finishes and 2 prints last

async function loadPage() {
  const menuPromise = fetch("/api/menu");
  const hoursPromise = fetch("/api/hours");

9 PREDICT THE OUTPUT

Code
async function getData() {
  try {
    const res = await fetch("/api/missing");
    if (!res.ok) throw new Error("HTTP " + res.status);
    const data = await res.json();
    console.log(data);
  } catch (err) {
    console.log("Caught:", err.message);
  } finally {
    console.log("Done");
  }
}

Output
Caught: HTTP 404
Done

Explanation
fetch gets a 404 response so res ok is false
the code throws an error HTTP 404 which skips res json and jumps straight to catch
catch logs Caught HTTP 404 and finally always runs at the end so it logs Done


10 WRITE THE CODE

Task
Write loadAndRender to show loading state fetch dishes render list items or show failure message

Code
async function loadAndRender() {
  const list = document.getElementById("list");
  list.innerHTML = "Loading...";

  try {
    const res = await fetch("/api/dishes");
    if (!res.ok) throw new Error("Failed to load");

    const dishes = await res.json();
    list.innerHTML = "";

    dishes.forEach(dish => {
      const li = document.createElement("li");
      li.textContent = dish.name + " - " + dish.price + " ETB";
      list.appendChild(li);
    });
  } catch (err) {
    list.innerHTML = "Could not load dishes.";
  }
}
